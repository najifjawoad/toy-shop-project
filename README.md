# ToyTopia

ToyTopia is a modern and visually engaging toy marketplace website. It showcases a collection of toys with category-based navigation, dynamic UI interactions, and a smooth user experience. The project is fully responsive and deployed on Netlify.

## 🧾 Project Overview

ToyTopia is a toy marketplace-style frontend project designed to display toys in different categories with smooth UI components. The website includes navigation, category filtering, responsive layouts, and rich visuals to enhance user engagement.

---

## 🛠️ Technology Stack

* **React.js**
* **JavaScript (ES6)**
* **Tailwind CSS**
* **DaisyUI**
* **Firebase Authentication** 
* **React Router DOM**
* **Netlify** (Deployment)

---

## ⭐ Main Features

* Fully responsive modern UI
* Category-based toy browsing
* Dynamic routing system
* User authentication system 
* Card-based product display
* Hover animations and smooth transitions
* Secure Authentication implemented
* Fast static deployment via Netlify

## 🖥️ Run Locally

Follow the steps below to run the project on your local machine:

1. **Clone the repository:**

```
git clone <your-repository-url>
```

2. **Navigate to the project directory:**

```
cd toy-topia
```

3. **Install dependencies:**

```
npm install
```

4. **Start development server:**

```
npm run dev
```

5. **Open your browser:**
   Visit the URL shown in the terminal, usually:

```
http://localhost:5173/
```
